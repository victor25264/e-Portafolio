#### System Logging, Forensic Analysis, and Technological Futures – From Internet Evolution to Generative AI

##### Logging, Forensics and Future Trends
+ Logging
  + log is a record of the events occurring within an organization’s systems and networks (Kent & Souppaya, 2006)
  + fundamental requirement of any system, as things will go wrong, we need a way to diagnose and isolate the cause (Eaton, 2003)
  + logs produce very valuable information about both traffic and also security incidents
  + all log messages consist of a timestamp, a hostname and an application field, as well as some indication of the status
  + most Unix derived systems (BSD, Linux) store their logs in the /var/log directory
  + Logs are grouped into various sets:
    + /var/log/boot.log keeps a history of boot-up messages
    + /var/log/maillog or /var/log/mail.log is used to keep a history of messages from whatever mail servers are running on the system
    + /var/log/kern contains a history of kernel generated messages
    + /var/log/dmesg contains a history of messages generated by devices and device drivers
    + There are various other logs including 
  +  key log management utility is logrotate which is used to manage the number of instances of each log to keep
  + Windows system, the default application used to access logs is the event viewer
  +  key questions around logs is where to store them – locally, remotely or both
  + sometimes a compromised machine may not be available or logs may have been deleted
  + modern solutions recommend that a central, secure syslog machine is set up to hold copies of syslogs from all machines
+ Logging Tools
  + Syslog-ng
    + available as an open-source (LGPL version) and as a commercial supported version
      + The default use of TCP links
      + Better filtering
      + More comprehensive routing options via templates
      + More accurate timestamps
  + Nagios
    + open-source monitoring solution
    + log aggregation and monitoring application
    + can it aggregate and monitor logs from virtually every other server availabl
  + Snort
    + main function is as an open-source intrusion detection/ prevention system
    + snort can detect OS fingerprinting and various penetration testing scans
+ Log Analysis Tools
  + webalizer
    + reports from the access logs 
    + produce daily, weekly, monthly and yearly
  + Security Information and Event Management (SIEM)
    + go-to tool for modern security professionals
    + pull together all sources of security alerts and events 
+ Digital Forensics
  + concerned with the recovery of digital evidence from storage media, computer systems, electronic devices and social media platforms
  + 4 phases to the process – collection, examination, analysis and reporting
  + due diligence should be ensured in any forensic investigation
  + key points:
    + make a backup of original data and work on that 
    +  verify that the system will be admissible as evidence
    + anyone working on the original system should be a 'competent person'
    +  there should be a case officer who is the responsible person who is well versed in legal and evidential processes and procedures
+ Secure Protocols
  + IPsec was designed to provide confidentiality integrity and availability
  + Authentication Header (AH)
    + authenticates but it does not encrypt
    + provide integrity by the use of a cryptographic hash
  + Encapsulating Security Payload (ESP)
    + encrypts the entire payload
    + IPsec can be used in 2 modes – either transport or tunnel mode
  + DNS is a fundamental component of the Internet
    +  a hierarchical system, based on top level domain (TLD) servers that manage domains
    + DNSSEC does not encrypt DNS messages. Instead it is a cryptographic authentication mechanism, like AH of IPsec
  + Secure Shell (SSH)
    + provided a secure tunnel that not only allowed remote login but also allowed a variety of other protocols
    + cryptographic keys to encrypt the network connection and can either authenticate via public-private key pairs or via simple passwords
  + HTTPS
    + secure version of the standard HTTP
    +  uses either SSL/ TLS to encrypt the layers below the application protocol laye
    + our versions of the hypertext transfer protocol 
      + v1.0 which used a new connection for every resource request
      + v1.1 was keep alive requests where a connection could be reused for multiple requests
      + v2.0  designed to compress and multiplex web content, as well as operate over TLS
      + v3.0 also known as HTTPS/3 QUIC, marks a major move to UDP away from TCP
+ Virtual Networking
  + network function virtualisation application areas
    + Mobile network nodes
    + Functions contained in home routers and set top boxes
    + Tunnelling gateway elements
    + Traffic analysis
    + Service Assurance, SLA monitoring, Test and Diagnostics
    + Application-level optimisation
    + Security functions
  + network function virtualisation risks
    + compromise hypervisor
    + isolation failure
    + platform integrity
    + DDoS attack
    + Malicious insider
    + Regultatory compliance
  + Software Defined Networking (SDN)
    + separate the data and control planes within an appliance
    + provides the advantages of NFVswith the flexibility of a user programmable architecture
    +  benefits of a SDN solution is the ability to mix and match controllers from various sources
    +  can provide additional and integrated security solutions for traditional network
+ Future Internet Architectures
  + Challenges:
    + Content Centric Networks
      + host centricity, is related to the fact that we still have to manage the internet as a collection of hosts
      + Content Centric Networks (CCN) is not new
      + Named Data Networking (NDN) which is a development of the original CCN 
      + NDN and CCN use a concept of interest packets (i.e. requests for data) and content packets
    + Overlay Networks
      +  take many forms from the widely spread CDNs, emerging technologies like SDNs and alternatives
      + allow a search string to be hashed and then used to search for content in a distributed network
    + Fog/Edge Computing
      + important factor for several years within enterprise computing
      + fog computing that brings together automobiles and the IOT together with cloud computing
    + 5G (MobilityFirst)
      +  field of research that best highlights the failings of the current internet and its conflation of identity and address
      + MF is based on GUID (globally unique ID) and a supporting GNS (global name service) that links the GUID to the appropriate network address (NA)

#### Reflexion
+ Logs are essential for early detection systems, incident response, and other security domains. Yet, many SMBs and even large enterprises still fail to follow best practices due to a variety of factors. These range from a lack of knowledge to budget constraints. However, when a security issue arises, the absence of comprehensive logs invariably penalizes organizations for this negligence.
