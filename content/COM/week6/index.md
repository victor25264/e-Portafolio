#### Hybrid Cloud Solutions (Hybrid, Fog, Edge Computing)

##### The NIST Cybersecurity Framework (CSF) 2.0 (National Institute of Standards and Technology (NIST), 2024)
+ Describes desirable outcomes for organization
+ Desing to be used by organizations of all sectors and sizes
+ Should be used with other frameworks
+ CFS Core:
  + high leve cybersecurity outcomes to manage organization cybersecurity risks
  + outcomes are sector, country and technology neutral and can be understood by a broad audience
  + Components:
    + Functions:
      + All functions relate to one another
      + should be addressed concurrently
      + All Functions have vital roles related to cybersecurity incidents
      + Govern (GV): 
        + cybersecurity risk management strategy, expectations, and policy are established, communicated, and monitored.
        + critical for incorporating cybersecurity into an organization’s broader enterprise risk management (ERM) strategy.
      + Indentify (ID)
        + current cybersecurity risks are understood
        + Understanding the organization’s assets, suppliers, and related cybersecurity risks
        +  prioritize its efforts consistent with its risk management strategy and the mission needs identified
        + identification of improvement opportunities for the organization’s policies, plans, processes, procedures and practices
      + Protect (PR)
        + Safeguards to manage the organization’s cybersecurity risks are used
        +  supports the ability to secure those assets to prevent or lower the likelihood and impact of adverse cybersecurity events
        +  include identity management, authentication, and access control; awareness and training; data security; platform security  and the resilience of technology infrastructure
      + Detect (DE)
        + possible cybersecurity attacks and compromises are found and analyzed
        +  enables the timely discovery and analysis of anomalies, indicators of compromise, and other potentially adverse events
        +  supports successful incident response and recovery activities
      + Respond (RS) 
        + actions regarding a detected cybersecurity incident are taken
        + supports the ability to contain the effects of cybersecurity incidents
        + cover incident management, analysis, mitigation, reporting, and communication
      + Recover (RC)
        + assets and operations affected by a cybersecurity incident are restored
        + supports the timely restoration of normal operations
        + enable appropriate communication during recovery efforts
    + Categories
      + Function is divided into Categories
      + related cybersecurity outcomes that collectively comprise the Function
      + are not exhaustive
    + Subcategories 
      + divide each Category into more specific outcomes of technical and management activities
+ CFS Organizational Profiles
  + mechanism for describing current and target cybersecurity posture
  + used to understand, tailor, assess, prioritize, and communicate the Core’s outcomes by considering an organization as a whole
  + Current Profile:  outcomes that an organization is currently achieving  and characterizes the extent each outcome
  + Target Profile:  desired outcomes that an organization has selected, considers anticipated changes to the organization’s cybersecurity posture
  + Community Profile:  
    + baseline of CSF outcomes that is created and published to address shared interests and goals among a number of organizations.
    + developed for a particular sector, subsector, technology, threat type, or other use case 
  + Repeat the steps as often needed
  + Steps:
    + Scope the organization profile:
      + document high level facts and assumptions to base the scope of the profile
      + organizations can have multiple profiles with different scopes
    + Gather the information neede to prepare the Organzation profile
    + Create the organization profile
      + detemine the selected outcomes and document needed information
      + consider using a community progile as a basis for the target profile
    + Analyze the gaps between the current and target profile
      + identify and analyze the differences between the current and target profile
      + develop a prioritized action plan
    + Implement the action plan, and update the Organizational profile
      + follow the action plan to address gaps
      + the action plan may have a overall deadline or be ongoing
+ CFS Tiers
  + applied to CSF organizational profiles to characterize the rigor of an organization cybersecurity 
  + provide context for how an organization views cybersecurity risk and processes
  + Tiers describe progration frfom informan to continous improvement:
    + Tier 1 - Partial
    + Tier 2 - Risk-Informed
    + Tier 3 - Repetable
    + Tier 4 - Adaptive
  + Tiers complement risk management methodology do not replace it
  + Progression to higher Tiers is encouraged when risks or mandates are greater or when a cost-benefit analysis indicates a feasible 


##### Security of serverless computing  (Ni, et al., 2024)
+ Serverless computing has recently been increasingly used in many areas
+ there are still many challenges in the design, implementation, and deployment of the serverless architecture
+ Cloud service providers attacks:
  + CSPs store customers’ data and All these data can be accessed by CSP
  + External hackers exploit vulnerabilities and could cause data modification and destruction
+ Cloud user:
  + Users often do not have very specialized security knowledge

##### Reflexion

+ Security in the cloud is a challenging field—different deployment models, such as IaaS, PaaS, or SaaS, change responsibilities and defense strategies. Also, as some security practitioners mention, cloud identities are the new perimeter. This expands the threat landscape, making organizations more flexible but with security challenges that need to be considered to avoid operational disruptions.
